## 11. P1-TK-REINIT-GATE：标准 TK clear→re-init 生命周期专项（2026-10-18）

> 背景：TB 线曾存在 WindMill 二次 setup 不回调缺陷（已修）。TK 线 provider 不同（FlameTKProvider →
> Taku ATAPI），作为同版本双线发布，必须独立验证 FlameSdk clear→re-init 公共生命周期契约。

实测（FreshStandardTKConsumer / 1.0.2 TK candidate / Xcode 26.0.1 / DT13 / 干净进程逐组执行）：

```
TK_R1（最小）：FI 274ms → clear → FI 24ms 回调 ✓          TK_FIRST_INIT = PASS
TK_R2（+Splash）：FI 85ms → clear → FI 27ms → FS load/show/close ✓
TK_R3（+Reward）：FI 131ms → clear → FI 26ms → FR load/show/reward(close) ✓
TK_R4（3 轮连续）：FI→clear→FI ×3 = 73/22/27ms 全回调 ✓      TK_REINIT_REPEAT_COUNT/PASS = 3/3

TK_SECOND_INIT_CALLBACK = PASS（4 轮全部回调，latency 22–27ms）
TK_REINIT_CALLBACK_TIMEOUT_COUNT = 0
TK_POST_REINIT_SPLASH = PASS   TK_POST_REINIT_REWARD = PASS
TK_REINIT_CRASH/EXCEPTION/TIMEOUT_COUNT = 0
TK_REINIT_DEFECT_CONFIRMED = NO   TK_HAS_SAME_REINIT_DEFECT_AS_TB = NO
TK_CLEAR_REINIT_TESTED = YES   TK_CLEAR_REINIT_SAFE = YES
```

结论：**TK 线（Taku ATAPI init）本身可安全重复 init，无 TB 式缺陷**——TB 缺陷根因是 WindMill
setup 一次性 completion，与 Taku init 路径无关；TK 无需任何修复。
标准双线 1.0.2 恢复：STANDARD_DUAL_LINE_1_0_2_PREFLIGHT = PASS / TECH_RELEASE_AUDIT_CANDIDATE = READY。
