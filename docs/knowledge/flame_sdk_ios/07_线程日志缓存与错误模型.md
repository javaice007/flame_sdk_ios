# 07 · 线程 / 日志 / 缓存 / 错误模型

> 代码证据：`core/FlameLogger.m`、`core/FlameErrorCode.{h,m}`、`utils/FlameConfigLocalStorage.m`、
> `utils/FlameNetworkUtils.m`、各 Impl 与 Adapter

## 线程模型（THREADING_MODEL_AUDIT = PASS）

- 原语：`@synchronized`（主力）+ `atomic` 属性 + `dispatch_once` 单例；**无** NSLock / 信号量 / 串行队列 / OperationQueue / async-await
- 网络回调：强制主线程（FlameNetworkUtils）
- init 链路：配置阶段主线程；TK Provider 同步（主线程）；TB Provider 回调线程由 WindMill 决定（未归一）
- 广告回调：**不包装**，三方 delegate 线程直接转发（Public callback 线程未统一）
- create/load/show/destroy：无主线程 enforcement（NOT_ENFORCED）
- 状态保护：init 状态机 / requestGeneration / Registry / Router 均 @synchronized ✅
- 特殊残留：FlameSdk.m / FlameConfigManager.m 多处「直接 IVAR 访问避免 atomic getter autorelease over-release」注释（历史 Debug 崩溃修复）

## 日志（FlameLogger）

- API：`+d/i/w/e:`；实现 **完全相同**（NSLog + TAG `FlameSDK` + 上下两条分隔 banner，每条消息 3 行）
- 无级别过滤、无开关、无 Debug/Release 区分、无脱敏、单一 TAG
- `setDebug:` 只作用于 AnyThink/WindMill 日志，与 FlameLogger 无关
- 调试残留：`[DIAG]`（指针/CFGetRetainCount）、`[TB_*_DIAG]` 在正式路径

## 缓存与持久化（CACHE_STORAGE_AUDIT）

| 存储 | 使用 | 内容 |
|---|---|---|
| UserDefaults（suite `flame_sdk_conf`） | ✅ 唯一持久化 | pt / aId / aKey(**明文**) / pMap(k=v& 串) / cv / cachedAt |
| Keychain / NSCache / FileManager / SQLite | ❌ | — |

- 内存态：`FlameConfigManager.appEntity`（atomic，@synchronized 写）
- 刷新：**每次 init 远端优先**，缓存仅网络失败兜底（无 TTL；cv/cachedAt 落盘但从不使用）
- pMap 序列化：`k=v&k=v` 自定义格式；解析按 `=`/`&` 切分且 `count==2` 才收录 → **value 含 `=`/`&` 的条目丢失**
- 广告对象：仅内存（adapter 强引用），无缓存池

## 错误模型（ERROR_MODEL_AUDIT）

- 形态：**NSString 错误码**（非 NSError/enum）；NSError 仅内部网络层（domain `FlameNetwork`）与三方原始错误，对外前转字符串
- 常量（FlameErrorCode.h）：

| 常量 | 值 | 含义 |
|---|---|---|
| ERROR_CODE_NOT_INIT | 14000 | 未初始化（含 Failed 后未 clear 重试） |
| ERROR_CODE_INVALID_APP_ID | 14001 | AppID 无效（TB 侧复用作 init 失败码） |
| ERROR_CODE_INVALID_PARAM | 14002 | 参数错误（TB Native 未知 feedADMode 也用） |
| ERROR_CODE_UNSUPPORTED_PLATFORM | 14003 | 平台不支持（含 TB SelfRender Banner 降级） |
| ERROR_CODE_INVALID_AD_PLACEMENT | 14004 | 广告位无映射 |
| ERROR_CODE_NETWORK_ERROR | 15000 | 网络错误（声明；实际网络失败直接透传 NSURLError code） |

- 裸字符串：`"-1"`（服务端响应异常）、`"AD_NOT_READY"`（实际不可达路径）、`"TK_PLATFORM_REQUIRES_ANYTHINK"`
- 三方错误码原样透传，与 14xxx 混在同一命名空间；**无统一错误模型/无对外 error domain/无映射层**
