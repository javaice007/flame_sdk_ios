## 产物形态

- **动态 Framework → XCFramework**，唯一二进制 `flame_sdk_ios.xcframework`
- 切片：`ios-arm64`（真机）+ `ios-x86_64-simulator`（**无 arm64 模拟器切片**，受国产广告 SDK 限制，Apple Silicon 模拟器需 Rosetta）
- 二进制动态依赖：`@rpath/AnyThinkSDK.framework`（**weak**，LC_LOAD_WEAK_DYLIB）、`@rpath/OpenSSL.framework`（强）
- 无 resource bundle / fat framework / 静态库变体
- Mach-O 级隔离设计（构建脚本实现）：
  1. AnyThinkSDK 弱链接 patch（TB 客户不携带 AnyThink 时 dyld 跳过）
  2. ToBid WindMill 静态归档隔离（剔除 `-framework Wind*` + `-undefined dynamic_lookup` + 临时隐藏归档）
