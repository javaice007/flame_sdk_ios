## 6. release branch topology（关键事实）

```
DOC_CLEANUP_START_HEAD = 4083b9ad263c8712495d5b49c2a73e37fef78160（upgrade/ios-taku-6.5.84）
```

本仓有**两个远端**，1.1.0 代码进入 release/ios-dual-line 的状态不同：

| 远端 | release/ios-dual-line | 状态 |
|---|---|---|
| `distribution`（github，正式分发仓） | **19903c2**（= RELEASE_COMMIT） | ✅ 1.1.0 代码已在基线（P5 发布时 fast-forward） |
| `origin`（gitee，开发仓） | `da19c68`（1.0.2 时期） | 本轮 ff 推进到最终 HEAD |

因此：**禁止再机械 merge upgrade/ios-taku-6.5.84 → release/ios-dual-line**（对 distribution 会产生重复 merge）。
两个远端的 release 分支均为 HEAD 的祖先（无分叉），P6 采用 `--ff-only` 线性推进，不产生 merge commit。
