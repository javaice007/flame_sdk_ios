# 09 · 可复用能力清单（REUSABLE_CAPABILITY_INVENTORY）

> 纯事实分类，不含新设计。分类定义：
> REUSE_AS_IS＝可直接复用；COPY_AND_ADAPT＝拷贝后需改造；REFERENCE_ONLY＝只作参考；
> DO_NOT_REUSE＝不要复用；不存在＝当前项目没有该能力。

| 能力 | 分类 | 事实依据 |
|---|---|---|
| Registry/Router/Provider 中介抽象（+load 注册、服务端 pt 动态激活、dispatch_once 兜底、@synchronized 线程安全） | **REUSE_AS_IS** | mediation/ 目录，双平台真机验证 |
| AES-GCM 加解密（OpenSSL EVP，IV12+CT+TAG16+Base64，按 key 长度选 128/192/256） | **REUSE_AS_IS** | utils/FlameAesCryptoUtils.m，TAG 校验完整 |
| 激励广告双平台适配链（At/Tb Reward 全事件映射 + 动态 presenter + stale delegate 守卫） | **REUSE_AS_IS** | adapter/tk、adapter/tb，TK/TB 真机闭环 |
| init 状态机（4 态 + 并发去重 + pendingCallbacks 队列 + hasCalled 防重回调） | **REUSE_AS_IS** | core/FlameSdk.m |
| 网络请求 generation 代际去重 + 可取消 + callback 强持有生命周期管理 | **REUSE_AS_IS** | core/FlameConfigManager.m:23-27,129-137 |
| XCFramework 构建脚本（AnyThink 弱链接 patch、WindMill 静态归档隔离、nm/otool 符号断言 fail-fast、幂等） | **COPY_AND_ADAPT** | xcFramework_build.sh；耦合本仓库 Pods 结构/绝对路径 |
| Splash 生命周期模式（5s tolerate timeout、finishOnce 幂等、动态顶层 VC） | **COPY_AND_ADAPT** | AtSplashAdapter.m / TbSplashAdapter.m |
| Native 双渲染模式（物料驱动 feedADMode 自动分支 + SelfRenderView 自绘 + clickableViews 合规插槽） | **COPY_AND_ADAPT** | At/TbNativeSelfRenderView、TbNativeAdapter.m |
| Banner SelfRender 物料模型 + RenderSlots 合规插槽（平台无关的物料驱动设计） | **COPY_AND_ADAPT** | FlameBannerAdMaterial.h / FlameBannerAdRenderSlots.h |
| 配置模型 + UserDefaults 双层缓存（远端优先/网络失败回退完整缓存） | **COPY_AND_ADAPT** | cv/cachedAt 死字段、pMap 序列化脆弱 |
| Network 基础封装（POST JSON + 主线程回调） | **COPY_AND_ADAPT** | 无重试、doPost 死代码 |
| 错误码常量表（14xxx/15000） | **COPY_AND_ADAPT** | 扁平但集中 |
| Release 文档规范（docs/releases 快照 + alpha 序号规则 + 版本矩阵） | **COPY_AND_ADAPT** | 引用了不存在的脚本 |
| MD5 签名工具 | **REFERENCE_ONLY** | MD5 + 无 nonce 的现实限制 |
| Logger | **REFERENCE_ONLY** | 无开关/无级别过滤/3 行 banner |
| @synchronized 全覆盖式线程模式 | **REFERENCE_ONLY** | 可用但无统一队列设计 |
| GroMore 直接集成 | **不存在** | CURRENT_DIRECT_GROMORE = NONE |
| eCPM 能力 | **不存在** | ECPM_PUBLIC_API = ECPM_INTERNAL_API = NONE |
| 服务端 reward verify | **不存在** | onAdReward 仅客户端平台回调 |
| CI / 发布自动化 | **不存在** | 无任何 CI 配置 |
| 单元测试体系 | **不存在** | 空模板 |
| Demo 工程 | **不在本仓库** | adsurge-ios-demo 独立仓库（Swift，用法见 08） |
| 同级 flame_sdk_ios research 空壳目录 | **DO_NOT_REUSE** | 仅 1 份历史 podspec |
