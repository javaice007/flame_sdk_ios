## 行为注意事项（对接/复用时必须知道）

1. **init Failed 后必须 `clear()` 再 init**（fail desc 有提示，头文件未文档化；Demo 以"每次 init 前 clear"规避）
2. **show 未 ready 仅打日志**：不回调 listener、无错误码（各类型 Impl 一致）
3. **create* 失败是同步回调 listener + 返回 nil**（不是只返回 nil）
4. **init success = 配置成功 + 聚合平台初始化成功**；缓存回退与远端成功对外无区别
5. **回调线程**：init 事实主线程（TB 线依赖 WindMill）；广告回调未归一——宿主自行 dispatch main
6. **TB 线 `isLoading` 恒 NO**、**TK 线 `onAdReward.transId` 恒空**、**TB 线 `onAdReward.userCustomData` 恒空**
7. **pIds value 不能包含 `=` 或 `&`**（否则本地缓存解析丢失）
8. TB SelfRender Banner 是**设计内降级**（14003），Demo 层用 NonRetryableErrorCodes 短路防重试风暴
9. 模拟器仅 x86_64 切片（Apple Silicon 需 Rosetta）；`-ObjC` 必须保留（+load 注册依赖）
10. TK/TB 两个 pod **互斥**；Flame 不触碰 ATT/IDFA/SKAdNetwork（宿主自理）
