# FlameAd iOS SDK 1.1.1.small.1 Release Notes

> 制品：同一 Git Tag `1.1.1.small.1` 下双产物（root=TK，`tb/`=TB），二进制与 1.1.1 发布字节完全一致

## Changed（相对 1.1.1 唯一变更 = 发布规格精简）

- TK `flame_sdk_ios`：移除 7 条非目标源依赖行（Sigmob/Baidu/MS/Funlink/AdGainSDK+TakuAdapter/FSUnion），
  保留 AnyThinkiOS 6.5.84 + OpenSSL + 自有酷盈（AdxSmartdigimktCNAdapter→SmartdigimktCNSDK 6.5.90）
  + 五组（CSJ+GroMore 双 adapter 共享 Ads-CN 7.8.0.5、GDT 4.16.10、快手 5.9.10.1、章鱼 ZY→OctopusSDK 2.6.10.7、倍孜 5.5.6.0）。
- TB `flame_sdk_ios_tb`：移除 5 条 subspec 依赖行（Baidu/MSAd/Mintegral/JuTui/Kuying），
  保留 ToBid-iOS 5.10.3 Core（内置 Sigmob）+ 五组（CSJ/GroMore(Full)/GDT/KS/Octopus/AdScope）。
- 底层 SDK 版本零升级；SDK 源码/框架产物零改动；公共 API 与 1.1.1 零差异。
- 互斥性延续：两 Pod 名不同、module 同名 `flame_sdk_ios`，禁止同一宿主混装。

## 验收与剩余风险

- 验收范围 = 正式发布成功 + 私有 specs 可见 + 全新消费者真远端拉取成功（CocoaPods 源码 git clone 新 Tag）。
- RUNTIME_AD_SMOKE=NOT_RUN（本轮不做真机/模拟器广告加载）。
- TK 离 30MB 门槛余量仅 0.58MB（1.9%），后续依赖任何升级都可能越线。
- 章鱼业务映射 OPEN：TK 线以 ZYAdapter（OctopusSDK 2.6.10.7）交付，依赖同源≠后台配置等价，待负责人确认。
- 版本串语义（Gem::Version）：`1.1.1.small.1` 为 prerelease 类字串——精确 pin `1.1.1.small.1` 可解析；
  无版本/普通范围要求不会命中本版本（不污染主线默认解析）；`~> 1.1.1` 亦不命中。
