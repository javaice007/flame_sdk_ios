## 分发架构（三仓库）

| 仓库 | 用途 | remote |
|---|---|---|
| 开发仓库 `flame_ios_sdk`（本仓库）| SDK 源码 + 文档 + 构建脚本；build/ 被 .gitignore | gitee.com/toowe-admin/flame_ios_sdk |
| 二进制分发仓库 `flame_sdk_ios` | 正式 `flame_sdk_ios.xcframework` + TK/TB podspec；Tag 归档含 xcframework（根目录）| github.com/javaice007/flame_sdk_ios |
| Specs 仓库 `flame-specs` | 正式发布的 podspec（`<pod>/<version>/<podspec>`）| github.com/javaice007/flame-specs |

**TK/TB 共用同一二进制仓库 Tag**：
- `s.source = { :git => 'https://github.com/javaice007/flame_sdk_ios.git', :tag => s.version.to_s }`
- `s.vendored_frameworks = 'flame_sdk_ios.xcframework'`（二进制仓库根目录）
- 1.0.0-alpha.1 已用此结构成功发布，1.0.0-alpha.2 沿用

**本地开发模式**：
- `xcFramework_build.sh` 构建产物同时复制到开发仓库根目录 `flame_sdk_ios.xcframework`（被 .gitignore 排除）
- 客户 `:path =>` 模式 pod install 时，CocoaPods 在仓库根目录查找 vendored_frameworks

## 依赖隔离口径（修正 5A.20 错误描述）

- **TK 包含共享的 ToBid Core（ToBid-iOS-RC 5.5.6 + ToBidSDK subspec），但不包含任何 TB 外部 Adapter**（CSJAdapter/GDTAdapter/BaiduAdapter/KSAdapter/MintegralAdapter/OctopusAdapter/MSAdAdapter/GromoreAdapter 全部不进 TK）
- **TB 包含 ToBid Core 和全部 8 个外部 Adapter，但不包含 AnyThink / TK 私有 Sigmob Adapter / AdGain / FSUnion**
- 5A.20 报告中"TK Podfile.lock ToBid 出现 0 次"是基于旧版本 0.1.8 测试，**1.0.0-alpha.2 的 TK 依赖树包含 ToBid-iOS-RC**（临时工程 `/tmp/flame-alpha2-tk-local` 验证）
