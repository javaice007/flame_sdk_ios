## 本版本主要内容

| 项目 | 本版本更新内容 | 更新目的 |
|---|---|---|
| 单二进制 | TK/TB 双线胶水同时内置 | 一个 binary 支持 TK/TB 双线运营 |
| pt 动态选择 Provider | FlameMediationRouter 按服务端 pt 激活 Provider | 后台灵活切换聚合平台 |
| AnyThink 弱链接 | LC_LOAD_WEAK_DYLIB | TB 客户不加载 AnyThink，避免 ADX 弹窗 |
| TB 不加载 AnyThink | TB podspec 不含 AnyThinkiOS | 隔离 TK 专属组件 |
| ToBid 5.5.6 | Core + Adapter 同版本 | TB 平台基础 |
| TB Splash | TbSplashAdapter | TB 开屏 |
| TB Reward | TbRewardAdapter | TB 激励视频 |
| TB Interstitial | TbInterstitialAdapter | TB 插屏 |
| TB Banner | TbBannerAdapter（含 SelfRender 14003 降级）| TB 横幅 |
| TB Native Express | WindMillNativeAdView 模板渲染 | Native 模板路径 |
| TB Native SelfRender | TbNativeSelfRenderView（复用 WindMill mainImageView/mediaView/logoView/dislikeButton）| Native 自渲染路径 |
| Native 物料驱动自动分支 | `_nativeAd.feedADMode` 决定 Express/SelfRender | 与 TK 行为一致 |
| 图片异步生命周期加固 | generation/cleanedUp/URL/View 身份校验 | SelfRender icon 竞态安全 |
| TB 广告源扩展 | 8 个 Adapter（5.5.6）| 用户选定全量接入 |
| TK/TB 依赖隔离 | Podfile.lock 互不污染 | 双线独立演进 |
