# FlameAd iOS SDK 1.1.1 Release Notes

> 发布基线：1.1.0 → **1.1.1**（Bugfix / 兼容性修复）；双线同版本
> 状态：**正式版（Released）**——tag `1.1.1` @ 042bf2d51575fa0b29592eefb6b448a0a1842736（双远端），正式产物 = RC 批准字节（验收见 docs/knowledge/flame_sdk_ios/38、39）

## Fixed

- 修复部分百度开屏图文素材场景下可能触发的 iOS 崩溃问题（图片渲染器异常导致的闪退）。
- TK 百度适配器升级至官方兼容版本。
- TB 聚合 SDK 升级至官方兼容版本。

## TK（`flame_sdk_ios`，Taku/TopOn 线）

| 依赖 | 1.1.0 | 1.1.1 |
|---|---|---|
| AnyThinkiOS | 6.5.84 | 6.5.84（不变） |
| AnyThinkMediationBaiduAdapter | 10.061.2.0 | **10.070.2.0** |

其余 12 项依赖与 1.1.0 冻结值一致（Pangle/GroMore 7.8.0.5、GDT 4.16.10、KS 5.9.10.1 等不变）。

随 ToBid 5.10.3 官方配套联动（官方 subspec 声明，非额外升级）：Pangle/GroMore 7.8.0.7、AdScope(BeiZi) 5.5.6.0、美数 2.7.25.0、章鱼 2.6.10.7、聚推 4.5.6.1、酷盈 6.5.90。不变：优量汇 4.16.11、快手 5.9.10.1、Mintegral 7.7.6；Sigmob 仍由 Core 内置。

## 双线

- 接入方式不变：客户侧仅需将 pod 版本号改为 `1.1.1`，无任何代码改动。
- **Flame 公共 API 相对 1.1.0 零差异**（全部公开头文件 diff = 0）。
- TK / TB 仍为两个互斥独立静态 XCFramework，minOS 13.0 不变。
- SKAdNetwork 配置与 1.1.0 一致，无变化。
