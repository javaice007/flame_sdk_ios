## 架构能力

| 项目 | 说明 |
|---|---|
| 单一 XCFramework | TK/TB 双线胶水同时内置，由 pt 字段动态激活 |
| TK/TB 双 Provider | FlameTKProvider / FlameTBProvider，+load 自动注册 |
| 服务端 pt 动态选择 | FlameMediationRouter 按服务端 pt 激活对应 Provider |
| 公共 API 一致 | TK/TB 客户使用同一组 Flame 公共 API |
| AnyThink 弱链接 | LC_LOAD_WEAK_DYLIB，TB 客户不加载 AnyThink |
| TK/TB 依赖隔离 | TK podspec 不含 TB 外部 Adapter；TB podspec 不含 AnyThink |
| 两个 Pod 互斥 | 不能同时接入 flame_sdk_ios 和 flame_sdk_ios_tb |
| TK/TB 版本一致 | 两个 podspec 始终使用相同版本号 |
