# FlameAd iOS SDK 1.1.0 Release Notes

> 发布基线：1.0.2 → **1.1.0**（双线大版本升级）；后续修复使用 1.1.x
> 状态：Release Candidate（RC checkpoint 见 docs/knowledge/flame_sdk_ios/31）；正式发布需 GPT 审查 + 项目负责人批准

## TK（`flame_sdk_ios`，Taku/TopOn 线）

- Taku Core 升级：AnyThinkiOS 6.5.71 → **6.5.84**（官方稳定版）
- Taku 官方广告源 Adapter 全矩阵升级：ADX 6.5.90.2.1 / GroMore 7.8.0.5.2.1 / GDT 4.16.10.2.0 / Baidu 10.061.2.0 /
  KuaiShou 5.9.10.1.2.0 / MS 3.0.15.0.2.0 / ZY 2.6.10.7.2.0 / Funlink 2.9.0.3.3.2.0 / BeiZi 5.5.6.0.2.0 / TTAdapter_Mix 7.8.0.5.2.1
- Sigmob：由历史 Flame 私有兼容 spec `flame_sdk_ios_tk_sigmob_adapter` 迁移为 Taku 官方 `AnyThinkMediationSigmobAdapter 5.1.3.2.0`
- **TK 正式去除 ToBid-iOS-RC 依赖**（TK 生产包零 ToBid/WindMill）
- Pangle/GroMore 成套升级至 7.8.0.5（单份 Pangle）
- AdGain 4.2.7.1 / FSUnion 1.0.8.0 保持（单独集成，非 Taku 下载中心范围）

## TB（`flame_sdk_ios_tb`，ToBid/WindMill 线）

- ToBid Core 升级：ToBid-iOS-RC 5.5.6 → **ToBid-iOS 5.10.1**（pod 名迁移 `ToBid-iOS-RC` → `ToBid-iOS`）
- Network SDK 全矩阵升级：CSJ/GroMore 7.8.0.5 / GDT 4.16.11 / Baidu 10.060 / KS 5.9.10.1 / MS 2.7.24.0 /
  Octopus 2.6.9.17 / Mintegral 7.7.6 / Sigmob（Core 内置）WindSDK 5.1.4
- **新增广告源**：JuTui 4.5.5.1 / AdScope 5.5.3.4 / Kuying 6.5.66
- SpriteKit 由 CocoaPods 依赖（Ads-CN 7.8.0.5）自动链接，无需手工配置

## 双线

- TK / TB 保持两个独立生产包，互斥接入；双线五类广告 API（Splash / Reward / Interstitial / Banner / Native）保持兼容
- **Flame 公共 API 相对 1.0.2 无 breaking change**（10 个公开头文件零差异）
- `-[FlameSdk getVersion]` 与初始化上报 version 修正为 1.1.0（1.0.2 曾漏改为 1.0.1-alpha.4）
- SKAdNetwork：客户 App 以 `doc/flame_doc/SKAdNetworkItems_merged_2026-10-20.plist`（119 条）为基准与自有 ID 取并集

## 验收口径

- 核心功能与五类广告 API 已在 adsurge-ios-demo 真机完成双线回归（含双线真实发奖 transId）
- 已真实验证广告源：TK = GroMore（REAL）、Taku ADX（BID_RESPONSE）；TB = Sigmob / GDT / CSJ（REAL）
- 其余广告源在当前测试位 waterfall 未命中，标 `PENDING_PRODUCTION_OBSERVATION`：不阻塞发布，将在实际线上 waterfall 命中后持续观察；如发现问题进入 1.1.x
